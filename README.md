# 🎓 College Event Portal

## 📌 Project Description

The **College Event Portal** is a responsive web application designed to provide information about college festivals and events. Students can view event details, schedules, gallery images, register for events, and contact the organizers.

## ✨ Features

* 🏠 Home page with festival highlights
* 📅 Event listings with date, time, venue, and description
* 📋 Event schedule
* 📝 Online event registration
* ✅ JavaScript form validation
* 🖼️ Responsive event gallery
* 📞 Contact section and contact form
* 📱 Mobile-friendly responsive design
* 🔄 Dynamic success messages using JavaScript
* 🔗 Event registration buttons with automatic event selection

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
* DOM Manipulation

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Use **Live Server** to run the project.
5. The website will open in your browser.

## 📝 Registration

Students can register by providing:

* Full Name
* Email
* Mobile Number
* Department
* Year
* Selected Event

JavaScript validates the entered information and displays a registration success message.

## 📱 Responsive Design

The website is designed to work on:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📟 Tablet

CSS media queries are used to make the website responsive.

## 🎯 Project Objective

The main objective of this project is to create a simple and user-friendly online platform for managing and displaying college festival events.
